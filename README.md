# Primitive DB

Учебное консольное приложение, имитирующее работу с базой данных.

## Требования

- Python 3.12 или выше.
- Менеджер проектов uv.

## Установка

После клонирования репозитория перейдите в папку проекта и выполните:

```sh
uv sync
```

## Запуск

```sh
uv run project
```

На текущем этапе программа выводит:

```text
DB project is running!
```

## Сборка пакета

```sh
uv build
```

Результаты сборки сохраняются в папке `dist/`.

## Проверка метаданных

```sh
uvx twine check dist/*
```
