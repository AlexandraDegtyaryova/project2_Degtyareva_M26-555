# Primitive DB

Учебное консольное приложение, имитирующее работу с базой данных.

## Требования

- Python 3.12 или выше.
- Менеджер проектов uv.

## Установка

После клонирования репозитория перейдите в папку проекта и выполните:

```sh
uv sync
```

## Запуск

```sh
uv run project
```

Программа запускает интерактивный ввод команд:

- `help` — показать справочную информацию.
- `exit` — выйти из программы.

## Проверка качества кода

Проверка правил Ruff:

```sh
uv run ruff check .
```

Форматирование кода:

```sh
uv run ruff format .
```

## Сборка пакета

```sh
uv build
```

Результаты сборки сохраняются в папке `dist/`.

## Проверка метаданных

```sh
uvx twine check dist/*
```
