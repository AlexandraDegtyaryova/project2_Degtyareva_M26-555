# Primitive DB

Учебная консольная база данных с управлением таблицами и CRUD-операциями:
созданием, чтением, обновлением и удалением записей.

## Требования

- Python 3.12 или выше.
- Менеджер проектов uv.

## Установка и запуск из исходников

После клонирования репозитория перейдите в папку проекта:

```sh
uv sync
uv run database
```

Прежняя команда `uv run project` также доступна.

## Управление таблицами

| Команда | Действие |
| --- | --- |
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать имена всех таблиц |
| `drop_table <имя>` | Удалить таблицу |
| `help` | Показать справку |
| `exit` | Выйти |

Поддерживаются типы `int`, `str`, `bool`. Имена таблиц и столбцов должны быть
идентификаторами: буквы, цифры и подчёркивания, без цифры в начале.
Имена чувствительны к регистру. Имена столбцов внутри таблицы не повторяются.
Столбец `ID:int` добавляется первым автоматически. Его можно указать явно,
но только один раз и только с типом `int`.

Пример сессии:

```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
>>>Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.
>>>Введите команду: list_tables
- users
>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
>>>Введите команду: drop_table products
Ошибка: Таблица "products" не существует.
>>>Введите команду: exit
```

Описание таблиц хранится в `db_meta.json` в текущей рабочей папке. Записи каждой
таблицы сохраняются отдельно: например, в `data/users.json`. Папка `data/`
создаётся автоматически. Структура и записи сохраняются между запусками.
При удалении таблицы удаляется и её файл записей.
Неизвестные команды, неверные аргументы и неподдерживаемые типы не меняют данные.
Повреждённый JSON вызывает понятную ошибку и не перезаписывается.

Команды таблиц разбираются через `shlex.split`, CRUD-команды — через `parser.py`,
который сохраняет кавычки вокруг значений. Команды приложения не выполняются
как команды Windows или Unix.

## CRUD-операции

Перед работой создайте таблицу:

```text
create_table users name:str age:int is_active:bool
```

### Создание записи — Create

```text
insert into users values ("Sergei", 28, true)
```

Передаются значения всех пользовательских столбцов в порядке их объявления,
без `ID`. Все поля обязательны. Строки заключаются в двойные или одинарные
кавычки; `int` задаётся целым числом, `bool` — `true` или `false`.
Пробелы, запятые и знаки равенства внутри строк сохраняются.

ID генерируется как `max(существующих ID) + 1`; для пустой таблицы — `1`.
Удаление строк не приводит к совпадению ID оставшихся записей.
После удаления максимального ID его номер может быть использован снова.
Пользователь не задаёт ID при вставке и не меняет его через `update`.

### Чтение — Read

```text
select from users
select from users where age = 28
select from users where name = "Sergei"
```

Результат выводится через PrettyTable с заголовками столбцов, в том числе
при пустом результате. `where` поддерживает одно условие равенства.

### Обновление — Update

```text
update users set age = 29 where name = "Sergei"
update users set age = 30, is_active = false where ID = 1
```

Обновляются все подходящие записи. Несколько присваиваний в `set` разделяются
запятыми. Проверяются существование столбцов и соответствие типов схеме.

### Удаление — Delete

```text
delete from users where ID = 1
```

Удаляются все записи, соответствующие условию. Для `update` и `delete`
условие `where` обязательно.

### Информация о таблице

```text
info users
```

Выводит имя таблицы, её столбцы с типами и количество записей.

### Пример полного цикла

```text
create_table users name:str age:int is_active:bool
insert into users values ("Sergei", 28, true)
select from users where age = 28
update users set age = 29 where name = "Sergei"
select from users
delete from users where ID = 1
info users
exit
```

## Сборка и проверка метаданных

```sh
uv build
uvx twine check dist/*
```

## Установка собранного приложения в Windows cmd

```bat
uv tool install --force dist\primitive_db-0.1.0-py3-none-any.whl
database
```

Параметр `--force` обновляет ранее установленный инструмент.
Если команда не найдена, выполните `uv tool update-shell` и откройте новый
терминал. Для проверки установленного инструмента отключите `.venv`
командой `deactivate`, если окружение было активировано.

## Проверка качества кода

```sh
uv run ruff check .
uv run ruff format --check .
uv run python -m unittest discover -s tests -v
```

## Структура кода

- `utils.py` — загрузка и сохранение метаданных и файлов записей.
- `core.py` — управление таблицами, проверка типов и CRUD-функции.
- `parser.py` — разбор значений, `where`, `set` и CRUD-команд.
- `engine.py` — справка, цикл ввода, PrettyTable и сохранение изменений.
- `main.py` — точка входа приложения.

## Демонстрация

[![Установка и управление таблицами](https://asciinema.org/a/HiDu5qHVdKIRWoEd.svg)](https://asciinema.org/a/HiDu5qHVdKIRWoEd)

В записи показаны установка пакета, создание таблицы, ошибки повторного создания,
просмотр списка, сохранение между запусками и удаление таблиц.
[Исходный файл записи](docs/tables-demo.cast) сохранён в репозитории.

Сценарий проверки установленного пакета:

1. Установить wheel командой из раздела установки.
2. Запустить `database`.
3. Выполнить `create_table users name:str age:int is_active:bool`.
4. Повторить создание и проверить сообщение о существующей таблице.
5. Выполнить `list_tables`, выйти и снова запустить `database`.
6. Проверить через `list_tables`, что таблица сохранилась.
7. Выполнить `drop_table users`, затем `drop_table products`.
8. Проверить пустой список таблиц и выйти командой `exit`.
